# Tokens

**Buscá el color por su nombre; no escribas un hex ni una fuente adentro de un
componente.** Si hace falta un valor que no está acá, se agrega al `@theme` de
`app/globals.css` y aparece en esta página — no se resuelve con una clase suelta
en una pantalla.

El archivo tiene dos capas: `@theme inline` define los **nombres** semánticos que
consumen los componentes, y `:root` los **valores** de este cliente. Cambiar de
cliente es cambiar la segunda capa; los componentes no se enteran.
